Fireworks, printed one row at a time.

Two small firework animations from 2023, sharing a repo. One prints asterisks in a terminal. The other draws circles in a pygame window. Same idea, two very different sizes of program.

Each row is 5 to 15 asterisks. That range is a choice in the code: shorter rows vanished in the scroll, longer rows looked like a solid bar.

What this is

I wrote the minimal script to see how little code a firework needs. The answer turned out to be one loop. Pick one of four colors, red, green, yellow, or magenta. Print a row of asterisks. Sleep a tenth of a second. Repeat forever, until Ctrl+C. There is no grid, no position tracking, and no burst shape. The terminal scrolling does the rest of the work, and I left blue and cyan out because they read badly on the dark terminal I ran it on.

The large script is the same idea with a window around it. It draws one burst per frame in pygame, wipes the screen, and draws the next one, so the show is a strobe of single bursts rather than a sky that fills up. A stick figure stands next to each burst. It is in this repo because it grew out of the small one, and my README says plainly that it is not ASCII.

Two details cost me real debugging time, so they are written down in the code. The minimal script flushes every row, because when its output is piped instead of shown on a terminal, Python holds the prints in a buffer and the animation appears to print nothing. And Ctrl+C is caught so the script prints the ANSI reset code on the way out. Without that, the last firework color stays active in your shell prompt.

The two scripts, side by side

minimal-fireworks.py
The ASCII one. Prints rows of asterisks in random colors and lengths in the terminal, forever, until Ctrl+C. Needs nothing but Python 3. Frame rate is a single time.sleep(0.1) call. Colors: 4. Row length: 5 to 15 stars.
large-fireworks.py
The window one. Draws filled circles in a 700 by 500 pygame window, with the stick figure from stick_figure.png following each burst. The trail is a ring drawn first, in the burst color with each channel halved, and the filled circle drawn over it. Needs pygame. Colors: 7. Radius: 10 to 50. Frame limiter: pygame.time.wait(100).

This is stick_figure.png, the one image the repo holds. The large script loads it from its own folder, so the script starts from any working directory. An earlier version used a bare relative path and crashed when launched from somewhere else. This repo has no banner or logo file, so this page uses this figure and the drawn bursts above instead of inventing art for it.

# the ASCII one, Python 3 only, stop it with Ctrl+C
